- 문단의 길이와 설명 호흡은 [v113-approved-writing-style.md](v113-approved-writing-style.md)를 최상위 기준으로 삼는다.

## 말투의 핵심

금손 말투는 단순히 친절한 존댓말이 아니다. 박준희 원장이 실제로 보고 느낀 것을 먼저 말하고, 독자가 겪는 장면을 이어 붙인 뒤, 왜 그런지 설명하는 1인칭 말투다.

1. `제가`, `저는`, `저도`로 원장의 판단을 숨기지 않는다.
2. `치료를 받아도 다시 아프죠?`, `그럴 때 보통 어떻게 하시나요?`처럼 독자에게 바로 묻는다.
3. `사실`, `그런데`, `하지만`, `그래서`는 실제 정정·대조·인과가 있을 때만 쓴다. `다시`, `따로`, `이어`도 실제 반복·분리가 있을 때만 쓰며 문장 연결 장식으로 넣지 않는다.
4. `~습니다`가 기본이지만 `~죠`, `~거든요`, `~더라구요`, `~세요`, `~네요`를 섞어 딱딱함을 푼다.
5. 짧은 단정문 뒤에 실제 동작·생활 습관·진료에서 보는 지점을 구체적으로 설명한다.
6. 치료를 무조건 권하지 않고, 필요 없는 치료를 더하지 않는 태도와 다른 검사가 먼저인 경우를 솔직하게 말한다.
7. 금손의 진료를 설명할 때는 `저희 금손한의원에서는·저는 진료할 때`처럼 주체를 밝히고, 무엇을 묻거나 진찰하는지와 그 이유를 직접 말한다.
8. `현재 상태·실제 변화·치료 순서·통증 단계`로 내용을 압축하지 않는다. 취침시간, 야간 각성 횟수, 고개가 걸리는 방향, 팔의 힘처럼 실제 질문 항목으로 풀어 쓴다.
9. `어떻게 달랐는지·이 차이를 함께 봅니다·증상에 따라 달라집니다·필요한 범위`처럼 구체적인 앞 문장에 기대어 뜻을 생략하는 후속 문장도 쓰지 않는다.
10. 한 문장에는 말하고 움직이고 보는 사람을 분명히 둔다. `고개를 돌려 보세요`처럼 직접 말하거나 `저는 환자에게 고개를 돌려 보게 합니다`처럼 진료 과정을 설명할 수 있으며, 어느 방식이든 실제 행동 주체가 모호하면 실패다.
11. 비교는 같은 종류끼리 한다. 환자가 짚은 무릎과 체중이 실리는 무릎은 비교할 수 있지만, 아픈 곳과 무릎을 같은 대상처럼 비교하지 않는다.
12. 정확 키워드는 `저희 {정확 메인키워드} 금손한의원에서는`으로 넣는다. 키워드가 `한의원`으로 끝나도 실제 병원명 `금손한의원`을 생략하지 않는다.
13. 환자만 느끼는 통증·저림·당김·메스꺼움은 묻고, 원장이 눈으로 볼 수 있는 뒤꿈치 들림·발목 흔들림·골반 기울임만 본다. 감각과 움직임을 `봅니다` 하나에 묶지 않는다.
14. 치료를 말할 때는 `어느 부위에 왜 치료하는지`로 줄이지 않는다. 침이면 어느 부위에 침을 놓는지, 진찰이면 어디를 누르고 어떤 동작을 시키는지 실제 행동을 쓴다.
15. 같은 `-다고·바로·시작`을 가까이 반복하지 않고, `치료 이름·같은 말·시작 시간`처럼 넓은 명사로 구체 내용을 다시 덮지 않는다.
16. `허벅지에 힘이 들어가다`처럼 힘을 추상적으로 쓰지 않고, 계단에서 허벅지가 떨리거나 몸이 기우는 실제 동작을 쓴다.
17. 번호 답은 `첫째는 … 것입니다·이럴 때 볼 것은 두 가지입니다`로 계산하듯 쓰지 않는다. 번호 소제목에서 완전한 결론이나 행동을 바로 말하고 마무리에서 번호 답을 다시 복창하지 않는다.
18. `사고가 난 시각과 통증이 시작된 날부터 묻다`, `잠·끼니·커피 가운데 언제`처럼 서로 다른 시간 단위와 생활 습관을 한 질문에 묶지 않는다.
19. `병원 진료부터 권하다·영상검사를 받을 수 있는 병원 진료·말하고 치료하다`처럼 명사와 조사를 겹치지 않는다. 안내·설명·치료의 실제 순서를 각각 쓴다.
20. `살핍니다·빼놓지 않습니다·빠뜨리시면 안 됩니다`로 질문을 생략하지 않는다. 무엇을 다시 묻고 환자가 무엇을 말해야 하는지 끝까지 쓴다.
21. 질문을 구체화한 뒤 한 줄씩 나열해 문진표로 만들지 않는다. 질문 뒤에는 그 질문이 필요한 이유, 환자가 겪는 장면, 원장의 판단을 자연스럽게 이어 쓴다.
22. 문단은 보통 두세 문장으로 읽히지만 문장 수를 맞추지 않는다. 한 문장으로 끝나거나 세 문장 이상 이어지는 편이 자연스러우면 그대로 둔다.
23. 번호 답 하나를 두 문단·네 문장으로 잘라 끝내지 않는다. 원인·생활 장면·문진·진찰·안전 기준·치료 판단을 독자가 이해할 만큼 여러 문단으로 충분히 설명한다.
24. 문진·신체 진찰·병원 검사·생활수칙·한의 치료를 종류별로 세어 제한하지 않는다. 소제목의 결론을 이해하는 데 필요한 내용이면 자연스럽게 이어 쓴다.
25. 같은 질문·누르는 진찰·동작 관찰도 도입, 본문, 마무리에서 역할이 달라 독자의 이해나 안전 행동을 다시 짚을 필요가 있으면 반복할 수 있다. 동일 문장을 분량 채우기로 복사하지 않는다.
26. 고정 인사 뒤에는 제목이 약속한 결론을 분명히 말하되 한두 문장으로 제한하지 않는다. `첫째·둘째를 살펴보겠습니다` 같은 글 진행 안내는 쓰지 않는다.
27. 마무리는 번호를 계산하듯 복창하지 않는다. 핵심 안전 행동이나 진료 기준을 다시 말할 이유가 있으면 한두 문단으로 자연스럽게 닫는다.
28. `그 답을 들은 뒤·질문이 달라집니다`처럼 실제 판단을 숨기는 문장보다 무엇이 어떻게 달라지는지 직접 말한다.
29. 첫 진료·치료 직후·다음 날·다음 방문의 시간축을 섞지 않는다.
30. 문장과 문단의 수가 아니라 주어·목적어·서술어 호응, 나열 수, 생략된 행동, 기본 동사와 오탈자를 우선 검사한다.
31. `접질린 뒤의 판단이 회복을 좌우합니다·다시 걷기 위한 출발입니다` 같은 표어형 결론 대신 구체 증상과 다음 행동을 말한다.

위 항목은 횟수 목표가 아니다. `제가`, `사실`, `그런데`, `~죠`를 최소 개수에 맞춰 끼워 넣으면 오히려 AI 말투가 된다. 1인칭은 확인된 원장 판단을 말할 때, 질문은 실제 독자 장면을 꺼낼 때만 쓴다.

## 이모티콘을 빼도 금손답게 쓰는 법

원문에는 `^^`, `ㅎㅎ`, `ㅠㅠ`, 하트와 이모지가 보이지만 사용자가 모두 금지했다. 이를 제거한 자리를 딱딱한 공문체로 메우지 않는다.

- 이모티콘 대신 원장의 실제 판단을 한 문장 넣는다.
- 감탄 부호 대신 구체적인 경험이나 생활 장면을 넣는다.
- 따뜻함은 `걱정되시죠?`, `저도 그럴 때가 있습니다`, `진료할 때 그 부분을 말씀해 주세요` 같은 실제 대화로 만든다.
- 지원되지 않은 개인 경험은 만들지 않는다. `clinic-facts.md`에 있는 경험만 쓴다.

## AI처럼 보이는 문장

다음은 기존 실패 원고에서 반복된 표현이다. 비슷한 기능의 문장도 피한다.

- `홍조 때문에 …나요?`와 `불면 때문에 …나요?`를 연달아 쓰는 증상명 치환형 질문
- `피로와 가라앉은 기분도 이어지나요?`
- `어느 불편이 하루를 가장 많이 흔드는지 알면 설명도 이어집니다.`
- `조금 더 분명히 구분할 수 있습니다.`
- `차분히 살펴보겠습니다.`
- `구체적인 단서가 될 수 있습니다.`
- `읽고 나면 무엇을 판단할 수 있는지 알 수 있습니다.`
- `오늘 정리한 두 조건을 차분히 확인해 보시기 바랍니다.`

`판단`, `기준`, `구분`, `확인` 같은 말 자체가 금지는 아니다. 다만 실제로 무엇을 보고 무엇을 할지 없이 이 추상어만 이어지면 실패다. 도입의 두 질문도 각각 자연스러워 보이는지만 보지 않는다. 두 질문을 이어 읽었을 때 같은 조사·같은 종결·같은 길이에 증상명만 갈아 끼운 구조라면 둘 중 하나의 시작 장면부터 다시 쓴다.

## 진료실 발화 가능성 검사

금지어 목록을 피하는 것이 목적이 아니다. 모든 문장은 `박준희 원장이 환자를 앞에 두고 실제로 이렇게 말할까?`를 기준으로 검사한다. 문법에 문제가 없어도 입으로 말하면 어색하면 실패다.

다음은 개별 문구가 아니라 전부 같은 실패 유형이다.

- `스스로 운동을 이어가지 마세요`처럼 안전 지시를 번역한 듯 완곡하게 돌려 말하는 문장
- `다시 아파지는 순간을 적어보세요`처럼 독자에게 기록·관찰·회상·정리 숙제를 습관적으로 주는 문장
- 행동 권유 뒤에 `실마리·단서·출발점·첫걸음·길잡이` 같은 추상적 보상을 붙이는 문장
- `몸이 보내는 신호에 귀 기울여 보세요`, `작은 차이부터 살펴보세요`처럼 감성적 여운을 만들기 위한 문장
- 글을 그럴듯하게 끝내기 위해 독자에게 교훈이나 다짐을 요구하는 문장
- `이번 글에서는`, `이 글을 통해`, `함께 살펴보겠습니다`처럼 실제 설명 대신 블로그의 진행을 안내하는 문장
- 필요한 의료 지시를 `~하는 편이 좋습니다`, `~해 보셔도 좋습니다`, `하나의 방법입니다`처럼 지나치게 완곡하게 만들어 의미를 흐리는 문장

안전 경계는 짧고 분명하게 말한다.

- `스스로 운동을 이어가지 마세요` → `혼자 판단해서 운동을 계속하시면 안 됩니다.`
- `무리가 느껴진다면 잠시 쉬어가세요` → `통증이 심해지면 운동을 멈추셔야 합니다.`

진료에 필요한 정보는 목적이 드러나게 말한다.

- `다시 아파지는 순간을 적어보세요. 그게 다음 실마리가 됩니다.` → `언제, 어떤 동작에서 다시 아픈지 진료할 때 말씀해 주세요.`
- `몸의 변화를 차분히 살펴보세요` → `운동 뒤 통증이 더 심해지는지는 확인해야 합니다.`
- `움직인 뒤 더 아픈지 꼭 보세요` → `움직인 뒤 통증이 더 심해지면 그 운동은 멈추세요.`

위 예시는 치환표가 아니다. 같은 생성 원리에서 나온 새 문장도 모두 다시 쓴다. `실제 환자에게 말해도 어색하지 않은가`, `한 번에 뜻을 알아들을 수 있는가`, `왜 이 행동이 필요한지 드러나는가` 세 항목 중 하나라도 아니면 짧고 직접적인 한국어 구어체로 바꾼다.

문장을 부드럽게 만드는 것보다 뜻을 분명히 전달하는 것이 우선이다. 중단해야 하면 `멈추셔야 합니다`, 하면 안 되면 `하시면 안 됩니다`, 진료에 필요한 내용이면 `진료할 때 말씀해 주세요`라고 단정적으로 말한다. 설명이 끝났다는 이유로 교훈·여운·감성 문장을 덧붙이지 않는다.

`현재 상태를 함께 살펴보겠습니다`, `치료 순서의 문제입니다`, `그 변화가 중요합니다`, `몸의 작은 변화를 보세요`도 같은 이유로 실패다. 실제 증상과 진료 행동 없이 친절하고 그럴듯하게만 들리기 때문이다. `통증이 계속되면 언제 아픈지, 어느 동작에서 심해지는지 진료할 때 묻습니다`처럼 내용을 바로 말한다.

`목·허리·머리가 어떻게 달랐는지 묻습니다`, `사고와 함께 말해야 합니다`, `이 차이를 함께 봅니다`, `검사가 필요한지는 증상에 따라 달라집니다`, `필요한 범위만 설명합니다`도 실패다. 각각 사고 당일과 다음 날의 실제 증상, 병원 검사가 먼저인 증상, 어느 부위를 왜 진찰하거나 치료하는지를 직접 적는다.

## 생활어 변환 검사

문법상 맞아도 환자가 평소 쓰지 않는 압축 표현이면 실패다. 특히 추상 명사에 `달라지다·이어지다·반복되다·차이를 만들다` 같은 작문용 서술어를 붙이지 않는다. 환자가 듣자마자 실제 동작이나 불편한 상태를 떠올릴 수 있어야 한다.

- `아픈 자리` → `아픈 곳`, `불편한 곳`
- `걷기가 달라지다`, `보행 양상이 변하다` → `평소보다 걷기 힘들다`, `걸을 때 자꾸 휘청거린다`, `한쪽 다리를 끌게 된다`
- `같은 자세가 다시 이어지다` → `치료 뒤에도 같은 자세로 오래 일하다`
- `부담이 반복되다` → `오래 앉아 일하면 목이 다시 뻐근해지다`
- `치료 방향에 차이를 만들다` → `언제 아픈지에 따라 치료 방법이 달라질 수 있다`
- `붓기가 커지다` → `붓기가 심해지다`, `다시 더 붓다`
- `두통이 덜 오다` → `두통이 덜 생기다`, `아픈 횟수가 줄다`
- `발목 근력과 균형이 돌아오다`, `발목이나 다리에 힘이 들어오다` → `한 발로 서도 발목이 흔들리지 않다`, `다친 쪽 다리로 몸을 지탱할 수 있다`
- `진료에서 말씀하다` → `진료할 때 말씀하다`
- `무리하지 않는 운동` → `가볍게 걷다`, `천천히 발목을 굽히다`
- `병원 검사가 급하지 않다` → `병원 검사를 먼저 받아야 할 증상이 없다`
- `먹고 언제 더부룩한지` → `식사 뒤 언제부터 더부룩한지`
- `출근·운전·운동 … 이 두 행동` → 세 항목과 두 행동의 개수가 다르므로 지시어를 빼고 세 행동을 그대로 다시 말함
- `오래 같은 자세로 일하다` → `같은 자세로 오래 일하다`
- `골절이나 인대 같은 구조 손상`, `골절이나 구조 손상` → `무릎뼈가 부러졌는지`, `인대가 다쳤는지`
- `한 발로 설 때 발목이 버티다` → `한 발로 설 때 발목이 흔들리지 않다`
- `다친 시각과 걸을 수 있는 거리를 듣다` → `언제 다쳤는지 묻다`, `지금 몇 걸음 걸을 수 있는지도 묻다`
- `병원 진료부터 말씀드리다` → `병원 진료를 먼저 권하다`
- `탄산음료 뒤에` → `탄산음료를 마신 뒤`
- `사고 직후 괜찮다고 몸에 이상이 없다고 넘기다` → `사고 직후 안 아파도 몸에 이상이 없다고 넘기다`
- `통증이 생기는 부위와 목이 돌아가는 정도를 보다` → `어디가 아픈지 묻고, 고개가 어느 정도 돌아가는지는 보다`
- `목 뒤쪽이 당기는지 보다` → `고개를 돌릴 때 목 뒤쪽이 당기는지 묻다`
- `트림이나 구역감이 생기는지도 듣다` → `트림이나 구역감이 생기는지 묻다`
- `어느 부위에 왜 치료하는지 설명하다`, `어느 부위에 침을 놓는지와 그 이유` → 실제 부위를 먼저 말하고 `왜 그 부위에 침을 놓는지 설명하다`
- `치료 이름부터 고르다` → `침이나 추나부터 정하다`
- `식사량과 시작 시간을 묻다` → `한 끼 식사량과 더부룩함이 시작되는 시간을 묻다`
- `허벅지에 힘이 들어가다` → `계단을 내려갈 때 허벅지가 떨리다`, `몸이 한쪽으로 기울다`
- `사고가 난 시각과 통증이 시작된 날부터 묻다` → `사고가 몇 시에 났는지 묻다`, `목이나 허리는 언제부터 아팠는지 묻다`
- `병원 진료부터 권하다` → `병원 진료를 먼저 권하다`
- `영상검사를 받을 수 있는 병원 진료`, `X-ray 검사가 가능한 병원` → `X-ray 검사가 필요하면 병원에서 먼저 검사받도록 안내하다`
- `어디에 침을 놓을지 말하고 치료하다` → 실제 부위와 이유를 두 문장으로 설명한 뒤 침 치료를 하다
- `침 치료가 필요한지 진찰하다` → 실제 동작과 촉진·문진을 먼저 쓰고 `진찰 결과에 따라 침 치료를 할지 정하다`
- `영상검사가 통증까지 대신 말해 주다` → 영상 결과와 계단에서 환자가 느끼는 통증을 따로 말하다
- `두 답을 들은 뒤` → 환자가 말한 답과 원장이 직접 본 동작을 각각 이름 붙이다
- `몇 시간 갔는지` → `몇 시간 동안 아팠는지`
- `진통제는 약 이름만큼` → `진통제 이름뿐 아니라`
- `검사받을 병원으로 안내하다` → `병원에서 먼저 검사받도록 안내하다`
- `편두통이 의심되는지 살피다` → `빛이나 소리에 예민한지, 메스꺼움이 함께 생기는지 다시 묻다`
- `잠을 못 잔 날도 빼놓지 않다` → `잠을 못 잔 다음 날 머리가 아팠는지도 묻다`
- `물을 거의 마시지 않는 일을 피하다` → `물을 조금씩 자주 마시다`
- `먹은 음식보다 먹는 방법까지` → `무엇을 먹었는지뿐 아니라 얼마나 빨리 먹었는지도 묻다`
- `빠뜨리시면 안 됩니다` → `진료할 때 말씀해 주세요`

위 문구로만 바꾸라는 뜻이 아니다. 초안을 다 쓴 뒤 문장마다 다음을 묻는다.

1. 환자에게 설명할 때 이 낱말을 그대로 입으로 말할까?
2. 환자가 듣자마자 어느 동작에서 어디가 어떻게 불편한지 떠올릴 수 있을까?
3. 같은 뜻을 `곳·때·하면·힘들다·아프다·뻐근하다`처럼 평소 쓰는 말로 더 쉽게 설명할 수 있을까?
4. 이 문장이 앞뒤 문맥에서 환자 장면, 원인, 문진, 진찰, 안전 행동, 치료 판단 가운데 실제 필요한 역할을 하는가?

하나라도 아니면 문장 구조부터 다시 쓴다. 어려운 낱말만 쉬운 낱말로 바꾸고 원래의 추상 구조를 남기지 않는다.

## 문자 그대로의 주어·서술어 검사

자연스러운 단어가 들어 있어도 주어·목적어·서술어가 실제로 맞지 않으면 AI 문장이다. 문장을 문자 그대로 한 번 풀어 보고 `누가 무엇을 하는가`, `무엇에 어떤 일이 생기는가`, `나열한 항목이 같은 조사와 문법 구조인가`를 확인한다.

- `아프지 않아도 사고가 끝났다고 단정하지 마세요` → `사고 직후 안 아파도 몸에 이상이 없다고 넘기시면 안 됩니다.`
- `걷는 것과 인대가 다치지 않았다는 뜻은 같지 않습니다` → `걸을 수 있다고 인대나 뼈가 다치지 않은 것은 아닙니다.`
- `아래 두 가지는 집에서 더 버티시면 안 됩니다` → `아래 증상 중 하나라도 있으면 집에서 더 버티시면 안 됩니다.`
- `붓기와 체중을 실을 때 통증이 계속됩니다` → `붓기가 빠지지 않고 발을 디딜 때 계속 아픕니다.`
- `체중이 쏠리는 장면을 진찰합니다` → `계단을 내려가게 하고 어느 무릎에 체중이 실리는지 봅니다.`
- `말이나 팔다리에 이상이 없는지 들어야 합니다` → `말이 어눌하거나 팔다리에 힘이 빠지지는 않는지 묻고 확인해야 합니다.`
- `소화제부터 다시 드실 일이 아닙니다` → `소화제를 다시 먹고 기다리시면 안 됩니다.`
- `계단을 다시 썼을 때` → `계단을 다시 오르내렸을 때`
- `환자가 짚은 아픈 곳과 체중이 실리는 무릎이 같은지 봅니다` → `어느 무릎이 아픈지 묻습니다. 계단을 내려갈 때 몸이 어느 쪽으로 기우는지는 직접 봅니다.`
- `고개와 허리를 직접 움직여 본 뒤 판단합니다` → `고개를 천천히 돌리고 허리를 숙여 보세요. 저는 고개가 얼마나 돌아가고 허리를 얼마나 숙일 수 있는지 직접 봅니다. 어디가 아픈지는 그 자리에서 묻습니다.`
- `배를 눌러 어느 곳이 아픈지 확인합니다` → `명치와 배꼽 위를 차례로 누른 뒤 어디가 아픈지 묻습니다.`
- `한의 치료를 적용할지 말씀드립니다` → `한의 치료를 시작할지, 병원 검사를 먼저 받을지 말씀드립니다.`
- `안 아픈 척 넘기지 마세요` → `사고 직후 안 아파도 그냥 넘기지 마세요.`
- `복숭아뼈 주변을 눌러 아픈 곳을 확인합니다` → `복숭아뼈 주변을 누른 뒤 어디가 아픈지 묻습니다.`
- `침 치료만 권해도 된다면` → `침 치료가 필요하고 다른 치료는 필요하지 않다면 침 치료만 설명합니다.`
- `얼음주머니를 대세요. 압박붕대를 감고 발을 올립니다` → `얼음주머니를 대세요. 압박붕대를 감으세요. 다친 발을 올리세요.`
- `위에서 음식이 천천히 내려가거나 위가 조금만 늘어납니다` → `밥을 먹고도 오래 답답한지, 몇 숟갈만 먹어도 배가 꽉 차는지 묻습니다.`

지역 메인키워드는 제목과 실제 진료 설명 안에 자연스럽게 넣는다. `광주 ○○ 한의원을 찾는 분이라면`처럼 검색 행동을 독자 호칭으로 바꾸지 않는다. 글 끝에는 `시간 내서 읽어주셔서 감사합니다` 같은 어느 글에나 붙는 인사를 덧붙이지 않는다.

`광주 ○○ 한의원 진료를 받으러 오셨다면`, `광주 ○○ 한의원 진료에서도`, `광주 ○○ 한의원에 오실 때는`, `저희 금손한의원은 광주 ○○ 한의원 진료에서`도 같은 SEO 작문체라서 실패다. 키워드 문장과 `저희 금손한의원에서는` 문장을 둘로 나누는 것도 실패다. `저희 광주 ○○ 한의원 금손한의원에서는 계단을 내려갈 때 어느 무릎이 아픈지 묻습니다`처럼 사용자 승인 구조 안에 정확 키워드와 실제 진료 행동을 함께 둔다.

점으로 나열한 추상 항목을 한 번에 묻지 않는다. `잠·식사·카페인·진통제를 묻습니다`는 `몇 시에 자는지, 끼니를 거르는지, 커피를 얼마나 마시는지, 진통제를 일주일에 며칠 먹는지 묻습니다`로 풀어 쓴다. 환자가 말할 수 있는 통증 장면과 원장이 직접 보는 발목·골반 동작도 분리한다.

## 한 문단을 쓰는 순서

1. 독자가 겪는 구체적인 장면을 한 문장으로 꺼낸다.
2. 박 원장의 솔직한 판단이나 진료에서 보는 지점을 붙인다.
3. 원인을 쉬운 말로 설명한다.
4. 꼭 필요할 때만 바로 해야 할 안전 행동이나 의료진에게 말할 내용을 구체적으로 제시한다.

모든 문단이 이 네 단계를 전부 가질 필요는 없다. 문단마다 같은 모양을 반복하면 다시 AI 말투가 된다.

모든 문단을 같은 문장 수로 맞추는 것은 실패다. 짧게 답할 곳은 짧게 끝내고, 설명이 필요한 번호 답은 여러 문단으로 충분히 쓴다. 질문만 문장별로 이어 붙이지 말고 왜 그 질문이 필요한지와 원장의 판단을 섞어 자연스러운 호흡을 만든다. 접속어 횟수를 맞추지 말고 실제 시간과 동작을 바로 말한다.

`A라고 단정할 수 없습니다 → 반대로 B라고 볼 수도 없습니다 → 사람마다 다릅니다 → 진찰이 필요합니다`처럼 대칭적인 안전 문장을 한 묶음으로 반복하는 것도 실패다. 문법과 개별 단어가 자연스러워도 사람이 같은 모양으로 계속 설명하지 않는다.

## 레퍼런스와의 분업
