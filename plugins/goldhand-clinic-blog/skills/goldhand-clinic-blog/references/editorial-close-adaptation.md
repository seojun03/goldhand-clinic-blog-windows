# 단일 레퍼런스 밀착 각색 계약

## 목적

자동모드는 주제를 가져온 공개 글 한 편을 `editorial master`로 고정한다. 이 글의 자연스러운 제목 문법, 독자가 질문하는 순서, 정보 공개 순서, 문장 호흡을 가까이 따르되 완성 문장은 금손한의원 원고로 새로 쓴다.

정규화된 `topicIdea`는 최근 3개 의미 중복 검사와 검색에만 사용한다. `먼저 볼 기록`, `판단 기준`, `생활의 흐름`처럼 정규화 과정에서 만든 표현을 제목·소제목·본문의 문구로 자동 전용하지 않는다.

## 한 글, 한 편집 마스터

- `topicIdeas[].sourcePostIds`가 여러 개여도 편집 마스터는 가장 직접 연결되는 원문 한 편만 고른다.
- 선택 결과에는 `editorialMasterId`, `editorialReferenceTitle`, `editorialReferenceUrl`, `editorialSourceRole`을 남긴다.
- `editorialSourceRole`은 `title-tone-content-sequence-only`다.
- 다른 글의 제목 패턴·질문 위치·전개를 섞지 않는다.
- 위석부부한의원 글에서 주제를 직접 고른 경우에는 그 글의 `WP...` 원문 한 편과 기존 `INFO...` 프로필이 같은 출처의 준비 완료 편집 마스터가 된다. 다른 Wipark 글을 다시 고르지 않는다.
- 고정 네이버 꾸밈과 운영정보는 편집 마스터와 무관하게 금손 디자인 시스템을 사용한다.

## 미감사 원문의 준비 단계

- `editorialProfileStatus=ready`인 결과만 바로 편집 마스터로 사용할 수 있다.
- `live-source-audit-required`이면 `editorialCandidate*`는 감사할 원문 후보일 뿐 master가 아니다. master 네 필드는 비어 있어야 한다.
- 정확한 후보 원문을 실제로 읽고 `sourceAuditStatus=body-reviewed`, 제목·말투 계약, 순서가 있는 `requiredContentBeats`, 각 비트 설명, 금지 재사용 항목만 담은 임시 프로필을 만든다.
- 원문 전체와 사진은 프로필에 저장하지 않는다. 복사 거리 검사용 본문 추출은 실행 임시파일로만 쓴다.
- 임시 프로필을 검증하고 그 프로필 파일로 선택기를 다시 실행해 `ready`를 확인한 뒤에만 원고·HTML·이력 기록으로 넘어간다.
- 원문 읽기나 프로필 검증이 실패하면 후보 URL을 master 속성에 복사하거나 다른 Wipark 글의 흐름으로 대체하지 않는다.

## 가까이 유지할 것

- 독자가 실제 검색할 때 쓰는 보통말: 예를 들어 `살이 안 빠진다`, `왜 그럴까요?`
- 제목의 질문형·이유형·비교형 문법
- 공감, 흔한 오해, 직접 답, 반문, 행동 기준이 등장하는 순서
- 소제목이 질문인지 결론인지와 같은 기능
- 짧은 결론문과 이유를 풀어 주는 문장의 교대
- 원문이 제목에서 약속한 핵심 정보 범위

흔한 검색 표현을 피하려고 `체중이 그대로라면 먼저 볼 기록`처럼 어색한 추상어로 치환하지 않는다.

## 반드시 새로 쓸 것

- 모든 완성 문장과 독자 질문의 정확한 문구
- 고유한 사례, 대화, 비유, 장면
- 업체명, 원장, 지역, 경력, 환자 수, 성과, 프로그램, 장비
- 사진, 캡션, 지도, 연락처, CTA
- 금손 사실과 권위 자료에 없는 수치·의학 답·치료 주장

레퍼런스의 업체·프로그램 홍보 절은 제거한다. 일반 의학 논리도 권위 자료와 공통되는 범위에서만 새로 설명한다. 의료 사실은 레퍼런스가 아니라 금손 사실과 별도 권위 자료가 결정한다.

## 표절 거리

- 원문과 완전히 같은 고유 문장을 쓰지 않는다.
- 일반적인 병명·치료명·짧은 검색어를 제외하고 7어절 이상 연속 일치를 허용하지 않는다.
- 원문의 고유 사례·비유·질문을 단어 몇 개만 바꾸어 옮기지 않는다.
- 제목은 흔한 검색 표현과 문법을 유지할 수 있으나 업체명·프로그램·경력·성과 수치는 제거한다.
- 완성 전 `validate_copy_overlap.py`로 원문 대조 검사를 수행한다.

## 사람다운 문장 검사

1. 메인키워드를 빼도 문장이 자연스러운가?
2. 실제 독자가 입으로 할 법한 질문인가?
3. `판단`, `기준`, `흐름`, `확인`, `먼저` 같은 추상어가 구체적인 장면을 대신하지 않았는가?
4. 선택한 레퍼런스와 같은 질문에 같은 순서로 답하는가?
5. 한 절이 체크리스트 문장만 이어지지 않고 짧은 답과 설명 문장을 섞는가?
6. 문장을 모바일 글자 수에 맞춰 다시 쓰지 않고, 완성 문장을 나중에 시각 줄로만 나눴는가?

`validate_editorial_fidelity.py`의 역할 순서 검사와 별도로 독립 검수에서 자연스러움과 레퍼런스 충실도를 각각 확인한다.

## SEO와 네이버 후처리

- 정확 메인키워드는 제목 1회, 일반 본문 2~3회만 자연스럽게 쓴다.
- 대표 독자 고민은 원문 방식에 따라 1~3개다.
- 해결 방향 예고는 한 번 두되 `읽고 나면 판단 기준이 생깁니다` 같은 고정 문구를 요구하지 않는다.
- 본문 요약표는 행·열로 볼 실질 정보가 있을 때만 쓴다.
- 고정 `금손한의원 소개` 가치입증 표는 도입 질문·인사·해결 방향 예고가 끝난 뒤, 첫 정보 본문 소제목보다 먼저 둔다. `before-credential` 실제 사진 1장 구성에서만 표 바로 위 사진을 허용한다. 고정 운영정보 표만 글 마지막에 둔다.
- 일반 원고를 먼저 완성한 뒤 모바일 줄바꿈·강조·순정 컴포넌트를 적용한다.

## 이번 기준 예시

원문 제목:

`대구 린다이어트, 운동을 해도 살이 안 빠지는 이유!`

가능한 금손 제목:

`광주 한의원 추천, 운동하는데 왜 살이 잘 안 빠질까요?`

피해야 할 제목:

`광주 한의원 추천, 운동해도 체중이 그대로라면 먼저 볼 기록`

원문의 핵심 흐름은 `운동의 중요성 인정 → 운동만으로 감소가 제한적인 이유 → 운동이 필요 없는지 반문 → 감량·유지에서의 역할 → 현실적인 관리`로 보존한다. 원문의 린다이어트 프로그램, 업체 주장, 고유 수치와 문장은 사용하지 않는다.
