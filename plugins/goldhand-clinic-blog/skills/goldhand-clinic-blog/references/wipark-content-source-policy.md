# 위석부부한의원 주제·내용 사용 규칙

## 역할

사용자가 지정한 위석부부한의원 블로그는 글의 `주제와 일반 정보 내용`뿐 아니라 독자를 설득하는 편집 방식을 제공한다. 선택한 한 편의 실제 질문, 제목 장치의 심리, 도입에서 부담을 낮추거나 궁금증을 만드는 방식, 핵심 정보 순서와 전환, 구체화 방식, 마지막 감정을 함께 따라야 한다. 제목 장치만 가져와 다른 내용을 쓰거나 금손 공통 템플릿으로 흐름을 덮으면 실패다.

자동 작성에서는 `assets/wipark-content-briefs.json`에 본문까지 검토된 11편만 사용한다. 2024-10-04 이후 다른 정보글을 새로 쓰려면 그 원문을 직접 읽고 같은 형식의 콘텐츠 브리프를 만든 뒤 사용한다.

## 선택한 한 편에서 반드시 가져오는 것

- 제목의 질환·생활 문제 또는 치료·제도 질문
- 도입의 대표 독자 고민
- 제목 장치가 독자에게 작용하는 이유
- 도입의 주의 장치·읽기 비용·주제별 보상
- 원문이 실제로 답한 핵심 일반 정보
- 정보가 공개되는 순서와 앞 문단이 다음 문단을 필요하게 만드는 전환
- 생활 장면, 반론 인정, 대비, 결론 우선 같은 미세 표현 기능
- 마지막에 회수하는 실제 답과 독자에게 남기는 감정

## 금손 글로 옮기지 않는 것

- 위석부부한의원 상호·지역·원장·경력·학력
- 환자 수·소개율·성과·효과 배수·치료 횟수·회복 기간
- 환자 사례·후기·직접 발화
- Human Anatomy Atlas·EFT 등 금손 자료에 없는 프로그램
- 원문 사진·연락처·지도·예약 링크
- 원문 문장과 비유

## 의료 내용 정리

`select_wipark_content_reference.py`가 내보내는 `orderedContentAtoms`를 같은 순서로 쓴다. 원래의 `orderedGeneralInformation`은 내용 누락을 감사하는 내부 자료일 뿐 초안 작성 패스에는 전달하지 않는다. 각 원자의 `observables`와 `meaning`은 완성 문장이 아니며, 조사와 종결어미만 붙여 본문에 복사하면 실패다. `blockedFromSource`는 삭제하거나 현재 공식 기준과 금손 사실로 안전하게 바꾼다.

보험 횟수·비용·약물 주의사항처럼 바뀔 수 있는 내용은 원문 숫자를 쓰지 않고 발행 시점의 공식 기준을 확인한다. 사용자가 직접 준 금손 사실은 그대로 사용한다.

## 표현 기능과 금손 생활어

위석 글의 완성 문장, 경력·환자 수, 치료 결과 단정, 강한 내원 유도는 쓰지 않는다. 그러나 `3분` 같은 숫자가 읽기 비용을 구체화하고 부담을 낮춘 뒤 주제별 보상으로 독자를 설득한다는 원리, 두 질문이 자기 대입을 만드는 방식, 결론을 먼저 주고 이유와 예외를 푸는 흐름은 `assets/reference-writing-intelligence.json`에서 해석해 옮긴다.

완성 문장은 `references/goldhand-official-voice.md`와 `references/natural-speech-rewrite-protocol.md`의 박준희 원장 생활어로 다시 쓴다. 이 과정은 레퍼런스의 편집 기능을 삭제하는 것이 아니라, 원문 문장을 복사하지 않으면서 금손 내용으로 자연화하는 단계다.
