# 금손 생활어 독립 검수 프로토콜

이 문서는 완성된 단일 구조 평문의 한국어만 검수한다. 글의 블록을 추가·삭제·이동하거나 다른 구조를 제안하지 않는다. 구조 판정은 [information-delivery-structure.md](information-delivery-structure.md)가 담당한다.

## 검수자 입력

- 확정 제목
- 공감 인용구부터 CTA까지 포함된 최종 평문 후보

검수자에게 SEO 수치, 메인키워드, 금지어 목록, 정규식, 기계 검사 결과, 정보 원자표, 출처 문장, 초안 작성자의 자기평가, HTML·이미지 계획을 전달하지 않는다.

## 검수 순서

### 1. 전체 낭독

처음부터 끝까지 소리 내어 읽는다고 생각하고 다음을 찾는다.

- 입에 걸리는 단어 결합
- 한 번에 뜻이 잡히지 않는 문장
- 문진표나 안내문처럼 이어지는 문단
- 같은 말을 표현만 바꿔 반복한 부분
- 소개 표 뒤 해결 예고, 번호 답, 정리와 CTA 사이의 갑작스러운 전환

구조 순서는 고치지 않는다. 연결이 어색하면 해당 블록 안의 문장을 다시 쓴다.

### 2. 문장별 반대 검토

모든 문장을 통과시키기 전에 실패할 이유부터 찾는다.

1. 한국인이 이 상황에서 자주 쓰는 단어 결합인가?
2. 입으로 말했을 때 자연스러운가?
3. 한 번 들으면 뜻이 바로 잡히는가?
4. 추상 명사보다 실제 사람과 행동이 보이는가?
5. 더 쉽고 익숙한 말을 쓸 수 없는가?
6. 주어·목적어·서술어가 문자 그대로 맞는가?
7. 수식어가 엉뚱한 대상에 붙지 않았는가?
8. 나열 항목의 문법 형태가 서로 맞는가?

한 문장이라도 실패하면 고친 뒤 전체를 다시 읽는다.

### 3. 사용자 교정 회귀

다음 차이는 단어 치환이 아니라 행동을 정확히 나누는 원리다.

| 실패 | 통과 | 생성 원리 |
|---|---|---|
| 다시 밤늦게 먹고 늦잠을 자나요? | 다시 야식 먹고 늦게 주무시나요? | 밤에 먹는 행동은 `야식 먹다`, 잠자리에 늦게 드는 행동은 `늦게 자다·주무시다`, 아침에 늦게 일어나는 행동은 `늦잠 자다`로 나눈다. |
| 거의 먹지 않았다면 원래 식사로 갑자기 돌아가지 마세요. | 굶다시피 살을 뺐다면, 다이어트가 끝났다고 갑자기 예전만큼 드시면 안 됩니다. | 식사를 돌아가는 장소처럼 다루지 않고, 바뀌기 전 행동·계기·바뀐 뒤 행동을 순서대로 말한다. |

검사어만 피한 비슷한 문장도 실패다.

### 4. 블록 안의 자연스러움

- 공감 질문이 실제 환자의 질문처럼 들리는가?
- 소개 표 내용을 앞뒤 산문에서 되풀이하지 않았는가?
- 3분 해결 예고가 광고 문구를 복사한 것처럼 들리지 않는가?
- 각 번호 소제목이 제목의 직접 답으로 읽히는가?
- 번호 소제목 안의 설명이 보고서처럼 같은 순서를 반복하지 않는가?
- 정리가 본문 복창으로 끝나지 않는가?
- CTA가 과장되거나 갑자기 영업 문구로 바뀌지 않는가?
- 마무리가 허용된 역할 A 또는 B를 하면서도, 다른 글의 틀에 질환명만 바꿔 넣은 문장처럼 들리지 않는가?
- `오늘 말씀드린` 같은 연결어가 없어도 방금 설명한 구체적인 내용이 자연스럽게 회수되는가?
- 감사의 뜻이 한 번만 나오고, 그 문장이 앞뒤 내용과 위치에 맞게 새로 쓰였는가?
- 여러 원고를 함께 검수한다면 같은 감사 문장이 반복되지 않았는가?
- 역할 A의 감사 뒤 문단이 자연스럽게 이어지고, 주제에 맞는 일반적인 설명이라는 경계와 직접 확인해야 할 이유를 모두 담았는가?
- 역할 B의 `n가지`가 제목의 답 개수와 맞으며, 그 내용을 참고했을 때 얻는 이득이나 피할 실수가 바로 이해되는가?
- 마지막 두 문단에 `금손한의원`, 지역 한의원 키워드, `저희 한의원`, 예약·문의·전화·내원 유도가 남아 있지 않은가?
- 진료 권유가 특정 병원으로 오라는 말이 아니라, 증상이 계속될 때 독자가 직접 상태를 확인해 보라는 중립적인 다음 행동인가?

### 5. 정보 보존

- 원래 정보와 의료 경계를 약하게 만들거나 빼지 않는다.
- 원자에 없는 원장 경험, 환자 사례, 치료 결과를 만들지 않는다.
- 제목 숫자와 서로 다른 실제 답의 개수를 유지한다.
- 자연스럽게 고쳐도 가치입증 표의 고정 문구는 바꾸지 않는다.

## 검수 기록

`independent-review.json`에는 다음을 기록한다.

- `contractId=goldhand-independent-natural-korean-review-v1`
- 초안 평문 파일과 최종 평문 파일의 SHA-256
- 초안 작성자와 독립 검수자의 서로 다른 식별값
- `reviewerRole=independent-natural-korean-spoken-editor`
- `draftReviewerSeparated=true`
- `reviewerInputMode=title-and-draft-plain-text-only-no-seo-forbidden-list-or-validator-results`
- 실제로 고친 전·후 문장과 구체 이유
- 서로 다른 블록 사이의 앞·뒤 문장을 인용한 흐름 확인 기록
- 보존한 원래 정보와 의료 경계
- 수정 뒤 제목부터 CTA까지 다시 읽은 구체 기록
- 남은 어색한 문장 0개
- 모든 발화 문장의 문자 그대로의 뜻을 확인한 범위

체크리스트의 값을 `true`로 채운 것만으로 검수를 통과시키지 않는다. 기계 검사는 알려진 회귀를 막는 안전망일 뿐 자연스러움을 대신 판단하지 않는다.

## 사용자 승인 경계

검수된 제목과 평문만 사용자에게 보여 준다. 사용자가 승인하기 전에는 HTML·이미지·표 꾸밈·강조·모바일 줄바꿈을 만들지 않는다. 수정 요청을 받으면 수정한 문장만 보지 말고 전체를 다시 낭독한다.
