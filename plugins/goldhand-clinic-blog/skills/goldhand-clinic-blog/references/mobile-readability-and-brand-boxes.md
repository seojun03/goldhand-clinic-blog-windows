# 승인 뒤 네이버 순정 표현

이 문서는 사용자가 평문을 승인한 뒤에만 읽는다. 승인된 문장과 [information-delivery-structure.md](information-delivery-structure.md)의 블록 순서를 바꾸지 않는다.

## 블록 변환

1. 공감 질문은 `blockquote` 순정 인용구로 바꾼다.
2. `[금손한의원 소개]`와 고정 행은 같은 위치의 `credential` 순정 표로 바꾼다.
3. 3분 해결 예고는 표 바로 다음 산문으로 둔다.
4. 번호 답은 `1.`부터 이어지는 순정 소제목으로 표시한다.
5. 정리 다음 CTA를 글의 마지막 블록으로 둔다.

## 모바일 줄바꿈

- 승인 문장 안에서 의미가 끊기지 않는 위치에만 `<br>`을 넣는다.
- 줄 길이를 맞추려고 단어·조사·어미를 바꾸지 않는다.
- 질문, 소개 표, 해결 예고, 번호 소제목, 정리, CTA의 순서를 바꾸지 않는다.

## 금손한의원 소개 표

- `assets/goldhand-value-proof-library.json`의 헤더와 행을 그대로 사용한다.
- 정확히 한 번만 쓴다.
- 공감 질문 뒤, 3분 해결 예고 앞에 둔다.
- 표 밖에서 같은 경력과 강점을 반복하지 않는다.

## 금지

- 해결 예고를 소개 표 앞으로 이동
- 소개 표 뒤에 사진이나 다른 산문을 끼워 해결 예고와 분리
- 번호가 없는 추가 주요 소제목
- CTA 뒤 운영정보 표, 지도, 관련 글, 또 다른 요약 자동 추가
- 승인 문장을 꾸밈에 맞게 재작성

이미지와 강조를 사용하는 경우에도 필수 블록 사이가 아니라 각 번호 소제목의 설명 안에서만 배치한다.
