# 의료·사실 표현 가드

## 기본 원칙

- 금손한의원 직접 정보는 사용자와 내장 스냅샷을 사실 입력으로 사용한다.
- 일반 의학 설명은 최신성이 있거나 임상 판단에 영향을 주면 현재 권위 자료를 조사한다.
- 외부 자료는 질환·증상·일반적 진료 원칙 설명에만 사용한다. 금손한의원의 성과·경력·환자 결과·보유 기술로 바꾸지 않는다.
- 완성 본문에는 논문명, 링크, 괄호 인용, 각주, 참고문헌 블록을 넣지 않는다. 내부 사실 팩에 출처 URL과 확인일을 남긴다.

## 외부 조사 우선순위

1. 정부·공공 보건기관과 공식 법령·행정기관
2. 관련 전문학회·공식 진료지침
3. 체계적 문헌고찰·메타분석·원문 연구
4. 대학병원·공공병원의 환자 정보

상업 병원 블로그, 건강식품 판매 글, 출처 없는 요약, 검색 결과 스니펫만으로 의료 설명을 확정하지 않는다. 자료끼리 다르면 더 보수적인 공통분모를 쓰고 개별 진찰 필요성을 밝힌다.

## 치료 표현

권장:

- `도움을 줄 수 있습니다`
- `환자의 상태에 따라 적용 여부가 달라집니다`
- `진찰 후 필요한 방법을 구분합니다`
- `통증 완화와 움직임 회복을 돕는 목적으로 활용합니다`
- `같은 증상이라도 원인은 다를 수 있습니다`
- `필요한 경우 다른 검사나 진료가 먼저일 수 있습니다`

금지:

- 완치, 치료 보장, 재발 방지 보장, 부작용 없음
- 무조건, 반드시 낫습니다, 즉시 회복, 한 번에 해결
- 100%, 1위, 유일, 최고, 가장 잘하는 곳
- 특정 기간 안에 좋아진다는 약속
- 진찰 없이 특정 처방·약재·치료를 독자에게 단정적으로 권하는 문장
- 타 병원이나 치료를 열등하다고 단정하는 비교

`예방`은 의학적 근거와 맥락이 명확하지 않으면 `위험을 줄이는 데 도움`, `초기에 상태를 확인`처럼 바꾼다.

## 사례와 개인차

사례·경과·효과를 다룬 글에만 다음 기능을 자연스럽게 포함한다.

- 한 사람에게 관찰된 경험이라는 범위
- 같은 증상도 원인·건강 상태·회복 속도가 다를 수 있다는 점
- 진찰 후 적용 여부가 달라질 수 있다는 점

고정 면책 문구를 복사해 모든 글에 붙이지 않는다. 사례의 실제 맥락에 맞춰 쓴다.

직접 인용은 공식 글이나 사용자 자료에 정확한 발화가 있을 때만 사용한다. `환자분들이 다들`, `많은 분이 효과를 봤다`, `소개가 끊이지 않는다`처럼 검증되지 않은 집단 반응을 만들지 않는다.

## 인증·자격 연결

허용:

- 11년차 한의사
- 한방비만치료 전문가과정 수료
- 보건복지부 인증 원외탕전실에서 제조한 약침 사용
- 정확한 과정명이 확인된 교육 수료

금지:

- 한방 비만 치료 인증 전문 한의사
- 비만 전문의, 통증 전문의, 소아 전문의
- 보건복지부 인증 약침치료
- 보건복지부 인증 골타요법
- 민간 명패를 정부 인증처럼 설명
- 사진만 있고 과정명이 확인되지 않은 수료증을 임의 명명

인증은 항상 인증을 받은 주체 바로 옆에 둔다. 문단을 갈라 인증 주체가 금손한의원이나 치료법으로 보이게 하지 않는다.

## 수치와 제목 약속

- 11년차와 2016년 개원은 사용할 수 있다.
- 운영시간과 주소·전화는 고정 블록에서 사용할 수 있다.
- 누적환자, 누적추나, 환자 수, 만족도, 소개율, 재방문율, 치료율, 지역 순위는 사용하지 않는다.
- 제목의 `2가지`, `3가지`, 기간, 거리, 횟수는 본문에 같은 수의 실제 답과 근거가 있어야 한다.
- 블로그 기존 제목의 숫자가 본문에서 설명되지 않으면 새 글에 재사용하지 않는다.

## 동적 사실

이 스킬은 사용자가 선택한 현재 스냅샷을 사용한다. 다음 값은 자동으로 현재 사실처럼 쓰지 않는다.

- 임시휴진, 원장 휴가, 당일 일정
- 주차 정산, 결제수단
- 건강보험 시범사업, 추나 보험·실비 조건, 본인부담
- 할인·이벤트·가격
- 방문진료 대상·비용·지역
- 비대면 처방 범위
- 직원·원장·베드·장비 수
- 학회 현재 회원 상태

사용자가 이 항목을 주제로 요청하면 필요한 현재 값만 질문하거나 명시적 검증 요청 범위에서 확인한다.

## 개인정보와 이미지

- 공식 블로그 이미지는 얼굴·이름·차트·연락처가 식별되지 않는 `safeAuto` 자산만 자동 사용한다.
- 사용자 제공 이미지는 사용자가 권한을 확인한 것으로 보고 별도 가림 질문 없이 사용한다.
- 텍스트에서는 사용자 제공 사례라도 이름, 연락처, 차트번호, 직장 등 불필요한 식별정보를 반복하지 않는다.
