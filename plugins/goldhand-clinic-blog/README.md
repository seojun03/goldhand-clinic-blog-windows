# 금손한의원 블로그 자동화

`독자 고민 질문 2~3개 → 고정 인사 → 해결 방향 예고 → 정보 본문`의 기존 형식을 그대로 유지하는 금손한의원 네이버 블로그 플러그인입니다. 사용자가 정한 주제에 맞는 저장 레퍼런스 여러 편에서 일반 정보만 모아 중복을 제거하고, 부족하면 한국어 네이버 검색을 브라우저 창이나 로그인 없이 백그라운드에서 실행합니다. 모든 완성 문장은 금손 공식 블로그 공개 글 74편을 분석한 박준희 원장 말투로 새로 씁니다.

본문까지 정밀 검토한 위석 정보글 11편은 저장 일반 정보 라이브러리의 시작 자료입니다. 사용자가 추가로 주는 레퍼런스도 출처 업체 정보를 분리한 일반 정보 원자로 저장할 수 있습니다. 어느 출처든 한의원명·원장·지역·경력·사례·성과·수치·프로그램·장비·연락처·사진은 전부 차단하며, 금손 업체 정보는 내장 사실 팩에서만 사용합니다. 완성 글은 정보전달형 한 종류만 씁니다.

## 바로 사용하기

- `$금손`처럼 스킬 이름을 직접 입력하거나 후보를 고를 필요가 없습니다. 새 작업에서 아래처럼 평소 문장으로 요청하면 금손한의원 플러그인이 자동으로 선택됩니다.
- `금손한의원 블로그 써줘`라고 하면 현재 자동화 버전을 먼저 안내한 뒤 정보형 글 주제 10개를 `1~10번`으로 추천합니다.
- 추천 번호를 고르거나 목록에 없는 원하는 주제를 직접 입력할 수 있습니다. 사용자가 처음부터 주제를 입력하면 10개 추천 단계는 건너뜁니다.
- 주제가 확정되면 `메인키워드를 입력해 주세요.`라고 묻습니다. 두 값이 모이면 메인키워드로 시작하는 공백 제외 30자 이내의 후킹 제목 5개를 추천합니다.
- 추천 번호 1~5를 고르거나 원하는 제목을 직접 입력할 수 있습니다. 제목이 확정되면 별도 모드 선택이나 추가 기획 질문 없이 자동으로 완성본까지 만듭니다.
- 저장 레퍼런스에 없는 주제도 거절하지 않습니다. 제목의 실제 답을 만들 정보가 부족하면 한국어 네이버 검색으로 보충하며 Windows에서도 사용자의 브라우저 화면이나 로그인 상태에 의존하지 않습니다.
- `2가지`, `3가지`처럼 숫자를 약속한 제목은 기존 글 구조 안에서 같은 개수의 서로 다른 번호 답으로 작성합니다. 기존 치료 보장·과장 표현 차단 규칙은 그대로 유지합니다.
- `글 주제는 오십견 치료 시기, 메인키워드는 광주 한의원`처럼 두 값을 처음부터 함께 주면 바로 제목 5개 추천 단계로 이동합니다.
- 결과는 `~/Desktop/금손한의원 블로그/금손한의원_{제목}.html`에 저장됩니다.
- 사용자 소유 callilife 작품을 우선 레퍼런스로 사용해 GPT Image 3~4장을 만듭니다. 주제와 맞는 작품이 부족하거나 OGQ 작품 목록·미리보기를 불러오지 못하면 사용자에게 링크를 요구하지 않고, 글의 설명 문단에 맞는 새 이미지를 callilife 그림체로 자동 생성해 계속 완성합니다. 시스템 `$imagegen`의 내장 생성 기능만 사용하며 OpenAI API 키를 요구하지 않습니다. 생성본은 원장 소개표 뒤 첫 두 개 설명 섹션 안에 넣고 최소 1장은 첫 섹션에 둡니다. 플러그인 안에 내장한 금손 공식 블로그 실제 사진은 원장 소개표 위 1장 또는 글마무리 신뢰 구간 2장으로 넣습니다. 여기에 검수된 원장·협약·수료·기부·봉사 사진 1장을 진료시간 앞에 별도로 두되, 사진을 소개하는 보이는 문장이나 캡션은 출력하지 않습니다. 다른 사용자의 바탕화면이나 개인 사진 폴더는 필요하지 않습니다.

## 공유본에 함께 들어가는 스킬

- `goldhand-clinic-blog`: 레퍼런스 선택, 금손 사실·말투 재구성, 의료 경계, 제목·도입·본문·마무리, 이미지·표·HTML 생성과 전체 검증을 담당합니다.
- `writing-voice`: 완성 산문을 말하는 속도로 다시 듣고 AI처럼 평평한 연결과 리듬만 국소 수정하는 최종 재청취를 담당합니다.
- 금손 스킬의 기본 실행 지시가 플러그인에 내장된 `$writing-voice`를 반드시 호출합니다. 따라서 공유받는 사람이 별도로 `writing-voice`를 설치하지 않아도 같은 최종 말투 검수가 적용됩니다.
- 글은 `clinic-info` 운영정보 표에서 끝납니다. 그 아래에 함께 보면 좋은 글, 최신 네이버 블로그 링크·카드, 네이버 지도·장소 컴포넌트는 만들지 않으며 나머지 출력 방식은 유지합니다.

## Windows 작동 계약

- 공유용 Windows 설치본은 짧은 영문 폴더에 전체 플러그인을 설치하고 `requirements-windows.txt`의 고정된 Python 패키지와 Windows용 `Asia/Seoul` 시간대 데이터를 설치해야 합니다.
- 결과 HTML은 Windows의 실제 바탕화면 위치를 사용하며 OneDrive 바탕화면도 인식합니다. 복사 안내는 `Ctrl+V`로 표시됩니다.
- GPT Image는 시스템 `$imagegen`의 내장 `image_gen` 모드로만 생성하며 `scripts/image_gen.py`·CLI/API 대체 경로와 `OPENAI_API_KEY` 요청을 사용하지 않습니다. 공유용 Windows 설치기는 Node.js LTS가 없으면 함께 설치하고 Vercel CLI까지 자동 설치·실행 확인합니다. 처음 설치할 때 `setup_image_host.py`가 일회용 코드가 이미 적용된 Vercel 승인 주소만 기본 브라우저에 열므로 사용자는 코드를 찾거나 입력하지 않고 본인 로그인 후 Allow만 누릅니다. 요청이 만료되면 새 승인 요청을 한 번 자동으로 열고, 이후 사용자 계정 안에 전용 이미지 프로젝트를 생성·연결·배포해 `image-host.json`까지 저장합니다. 비밀번호·토큰·일회용 코드·승인 주소는 플러그인 설정에 넣지 않습니다. 공개 HTTPS 게시 단계에서는 Windows npm shim인 `vercel.cmd`를 우선 인식합니다.
- 공유용 macOS 설치본은 Windows 배포와 별도 저장소·설치 폴더·마켓플레이스로 운영합니다. macOS 전용 관리 런타임과 Vercel 실행기는 `${CODEX_HOME:-$HOME/.codex}/state/goldhand-clinic-blog` 아래에 보존하므로 플러그인 업데이트 후에도 최초 연결을 다시 요구하지 않습니다.
- 글쓰기·말투·표·이미지·HTML 규칙은 운영체제별로 나누지 않습니다. 같은 콘텐츠 계약 검사를 Windows 배포 CI에서도 실행해야 합니다.

## 단일 원본과 업데이트

편집 원본은 이 플러그인의 `skills/goldhand-clinic-blog/` 하나뿐입니다. 사용자 스킬 폴더에 별도 복사본이나 심볼릭 링크를 만들지 않고, 개인 마켓플레이스에 설치된 플러그인 경로로만 노출합니다. 그래야 `$` 자동완성에 같은 금손 스킬이 두 번 나타나지 않습니다.

플러그인 소유자 환경에서는 플러그인 소스를 수정한 뒤 아래 명령을 실행하면 중복 직접 링크를 안전하게 정리하고, 버전 캐시버스터를 갱신한 뒤 개인 마켓플레이스에서 다시 설치합니다. 소유자 전용 `~/.codex/state/goldhand-clinic-blog/publisher.json`에서 `autoPublish: true`가 설정되어 있으면 전체 콘텐츠 테스트와 Windows 배포 검증을 통과한 뒤 GitHub `main` 푸시, Windows CI 확인, 새 Release 생성, 공개 자산 재다운로드·SHA-256 검증, 공개 설치 경로 테스트까지 자동으로 이어집니다. 실패한 변경은 Release로 공개하지 않습니다. 이 설정과 GitHub 권한은 사용자 설치본에 포함하지 않습니다.

```bash
python3 ~/plugins/goldhand-clinic-blog/scripts/refresh_plugin.py
```

설치된 플러그인 캐시는 열린 작업에서 즉시 다시 읽히지 않을 수 있으므로, 새로고침 명령이 끝난 뒤 새 Codex 작업에서 시험합니다.

## 콘텐츠 경계

- 허용 형식: 대표 독자 고민 인용 2~3개, 해결 방향 예고 한 문단, 정보 본문
- 제외 유형: 업체소개형, 사례공유형, 스토리텔링형, 일상글, 진료 공지, 행사 기록
- 관련 저장 레퍼런스 여러 편과 필요한 네이버 자료에서 일반 정보만 모아 의미 중복을 제거합니다.
- 기존 제목·도입·본문·마무리 구조는 단일 편집 마스터 한 편만 담당하며 콘텐츠 출처가 늘어나도 바꾸지 않습니다.
- 말투는 `goldhand-official-voice-v1` 하나로 고정합니다. 금손 공식 74편에서 확인한 1인칭 판단, 독자 질문, 구체적인 생활 장면, 자연스러운 종결어미 혼합을 사용합니다.
- `ㅎㅎ`, `ㅠㅠ`, `^^`, 하트, 이모지를 차단합니다. 특정 금지 문장만 피하는 방식이 아니라 실제 진료실에서 말하지 않을 번역투 명령문, 독자 숙제형 기록·관찰 권유, 실마리·출발점 같은 감성적 추상 결론을 같은 문장군으로 묶어 차단합니다.
- 모든 문장은 “박준희 원장이 환자 앞에서 실제로 이렇게 말할까?”를 검사하며, 어색하면 짧고 직접적인 한국어 구어체로 다시 씁니다.
- 여러 관련 글의 일반 정보는 합칠 수 있지만 다른 한의원의 특징·수치·사례·문장·사진은 사용하지 않습니다.
- 금손한의원·박준희 원장·진료·운영 정보는 `references/clinic-facts.md`에서만 넣습니다.
- 일반 본문은 모바일 기준 의미 단위 2~3줄 뒤에 빈 줄을 두며, 인용구·인사·소제목·본문·캡션·표까지 모두 중앙 정렬합니다.
- 정확 메인키워드는 제목에 1회, 일반 본문에 1~2회만 자연스럽게 사용합니다.
- 글 끝에는 제목과 본문에 맞춘 마무리 소제목, 순정 구분선, 핵심 내용 회수, 부담 없는 진료 안내를 둡니다. 특정 레퍼런스의 `25년 경험이 전하는 한 가지` 같은 문구를 고정 공식으로 반복하지 않습니다.
- 핵심 결론에는 노란 하이라이트 2~3개, 행동 기준에는 밑줄 2~3개, 중단·검사·주의 같은 안전 경계에는 빨간 글씨 1~2개를 사용합니다.
- 외부 CSS 카드와 1행×1열 가짜 표는 쓰지 않습니다. 독자 질문은 네이버 순정 인용구, 절 구분은 순정 구분선, 가치입증·요약·운영정보는 회색 셀 구분선과 중앙 정렬을 적용한 순정 표1 `goldhand-naver-native-v4`로 모든 글에서 동일하게 유지하며 운영정보 표는 좌우 50:50으로 고정합니다.
- 가치입증은 후보 선택 없이 “금손한의원 소개”와 고정된 짧은 경력·강점 6행을 항상 같은 순서로 사용합니다.
- 금손 골드는 실제 표의 셀 배경과 글자색에만 제한하며, 표와 산문에서 같은 내용을 반복하지 않습니다.
- 본문 속 중복 제목이나 영문 브랜드 띠는 만들지 않습니다.
- 실제 사진 1장 구성은 해결 방향 예고 뒤 원장 소개표 바로 위에 두며 해당 문단과 장면을 맞춥니다. 2장 구성은 마무리 뒤 진료시간 안내 직전에 두고, 글의 질환·부위와 달라도 시각 검수된 실제 치료·진찰·상담·검사 사진이면 사용합니다. 2장 구성은 직전 글 미사용 사진을 우선하고 부족하면 승인 사진을 재사용해 사진을 빼지 않습니다. 설명 본문 중간에는 흩어 넣지 않으며 환자 얼굴·이름·연락처·차트 등 개인정보 위험 사진과 미검수 사진은 사용하지 않습니다.
- 일반 의학 설명은 공공기관·전문학회·원문 연구처럼 권위 있는 출처를 내부 조사에만 사용하고 완성 본문에는 출처 목록을 노출하지 않습니다.
- 치료효과 보장, 근거 없는 수치, 전문기관 오인 표현, 강한 내원 유도는 발행 게이트에서 차단합니다.
