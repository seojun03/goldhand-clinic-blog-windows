# 금손한의원 블로그 자동화

금손한의원 정보전달형 글을 한 가지 구조로 작성하는 플러그인입니다.

```text
제목
→ 독자가 실제로 떠올릴 질문 인용구
→ 금손한의원 소개 표
→ 3분만 읽었을 때 얻을 이득 또는 피할 손실
→ 제목 숫자와 일치하는 번호 소제목 n개
→ 글 전체 정리
→ CTA
```

위 순서 외의 다른 글 배열은 사용하지 않습니다. 외부 레퍼런스는 각 블록의 역할과 일반 정보만 확인하며 문장, 업체 사실, 사례, CTA는 복사하지 않습니다.

## 사용 흐름

- 주제가 없으면 다이어트·교통사고·비염처럼 짧은 주제 키워드 10개를 번호 목록으로 제안합니다. 설명이나 제목형 문장은 붙이지 않습니다.
- 제목이 없으면 서로 다른 답을 확보한 뒤 그 개수 n을 표시한 숫자형 제목 5개를 제안합니다.
- 메인키워드와 SEO는 기본 입력·작성·검수에서 제외합니다.
- 추천 제목 선택 또는 직접 제목 입력 뒤 `'{주제}'에 대해 중요하게 생각하는 {N}가지가 무엇인가요?`라고 인터뷰하고 답변을 기다립니다. 주제는 사용자가 선택·입력한 원문, N은 제목의 `N가지`입니다. 숫자가 없는 제목은 중요하게 생각하는 내용을 개수 없이 묻습니다.
- 사용자 답변을 반드시 번호 소제목과 본문 설명의 중심으로 삼습니다. 저장 자료는 그 내용을 보충하는 데만 쓰며, 사용자 항목을 임의로 바꾸거나 빠뜨리지 않습니다.
- 인터뷰 답변과 필요한 누락·충돌 확인 뒤에는 평문 승인이나 이미지·HTML 진행 여부를 다시 묻지 않습니다.
- 평문 작성과 독립 생활어 검수를 내부에서 마친 뒤, 검수된 문장을 바꾸지 않고 네이버 순정 인용구, 금손한의원 소개 표, 소제목, 이미지·디자인·HTML까지 자동으로 완성합니다.
- 이미지 작업을 할 수 없거나 실패하더라도 사용자에게 선택을 묻지 않고 이미지 없는 완성본으로 마무리합니다.
- CTA가 글의 마지막 블록이며 운영정보 표, 지도, 관련 글을 자동으로 붙이지 않습니다.
- 마지막 두 블록은 `주제별 도움 인사 → 문맥에 맞게 새로 쓴 감사 → 일반 정보 경계와 중립적인 진료 권유` 또는 `제목과 같은 n가지가 주는 이득·피할 실수 → 중립적인 다음 행동 → 문맥에 맞게 새로 쓴 감사`의 역할을 합니다. 감사 예시는 고정 문구가 아니며 여러 글에 같은 문장을 반복하지 않습니다.
- 마무리에는 금손한의원·지역 한의원 키워드·예약·문의·전화·내원 유도를 넣지 않고, 불편이 계속될 때 독자가 직접 진료를 받아보도록 중립적으로 권합니다.

## 글쓰기 기준

- 실제 한국인이 자주 쓰는 단어와 문장
- 한 번 읽거나 들으면 바로 이해되는 표현
- 박준희 원장이 환자 한 명에게 설명하는 말투
- 사용자 확정 제목과 의학적 의미 보존
- 다른 업체의 사실·문장·사례 차단
- 치료 결과 보장과 압박성 CTA 금지
